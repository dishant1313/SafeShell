# Rubric Mapping

- **Novelty**: Fuses LLM planners with strict OS-level simulation and determinism.
- **Feasibility**: Uses standard Linux primitives (OverlayFS, Namespaces).
- **AI Approach**: "AI proposes, never decides" mitigates hallucination risk.
- **Security**: Denylist, Sandbox, Policy-as-Code.
- **Alignment**: Human-in-the-loop (TUI), clear English explanations.
